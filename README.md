# 智能猫咪喂食机小程序原型

这是根据 `智能喂食机技术实现方案.pptx` 搭建的微信小程序前端原型，当前使用模拟数据，便于先确认页面流程。

## 页面

- 首页：设备在线状态、温湿度、猫粮余量、低余量提醒、立即喂食、今日计划。
- 喂食：手动喂食份数、发送喂食指令、添加定时计划、启停计划。
- 数据：按日期查看温度趋势、猫粮余量趋势和历史事件。
- 抓拍：远程拍照、模拟红外触发、猫咪识别规则、抓拍记录。

## PPT 功能映射

- SG90 舵机喂食：对应“立即喂食”和“定时计划”。
- HX711 余量检测：对应首页余量、低余量提醒和数据页余量曲线。
- DHT22 温湿度：对应首页温湿度和数据页趋势。
- HC-SR501 + 摄像头 + YOLOv5-Nano：对应抓拍页的红外触发、识别提醒和远程拍照。
- MQTT/云端同步：后续可替换 `utils/mock-device.js`，接入真实设备数据和指令下发。
